📌 Project Title

Financial Health AI – AI-Powered Fintech Dashboard for SMEs

## 🔗 Live URLs
- Frontend: https://financialhealthassessment.netlify.app
- Backend API: https://financial-health-ai-backend-3.onrender.com

🧠 Problem Statement

Small and Medium Enterprises (SMEs) often lack clear visibility into their financial health. They struggle with cash flow management, compliance risks (such as GST), and understanding financial data for decision-making. Existing financial tools are complex, fragmented, and not intelligent enough to provide actionable insights.

💡 Solution

Financial Health AI is an AI-powered fintech dashboard that provides SMEs with a single, intuitive platform to assess their financial health, monitor risks, forecast cash flow, and track GST compliance.

The system transforms raw financial data into clear insights and visual indicators, enabling better financial decisions.

🚀 Key Features

Financial Health Score (0–100) – Quick assessment of business health

Risk Alerts Panel – Identifies red flags in financial data

Cash Flow Forecast Chart – Visual prediction of inflows and outflows

GST Compliance Checklist – Helps ensure regulatory compliance

AI Insights Panel – Actionable recommendations powered by AI logic

Language Toggle (EN / HI) – Improves accessibility for Indian SMEs

Secure Authentication – Login, registration, and password recovery

🛠️ Technology Stack

Frontend: React, Vite, Recharts

Backend: FastAPI (Python)

Containerization: Docker

Deployment:

Frontend → Netlify

Backend → Render

API Communication: REST APIs with CORS-enabled security

🌍 Impact

This platform empowers SMEs by:

Improving financial awareness

Reducing compliance risks

Enabling proactive financial planning

Making AI-driven insights accessible to non-technical users
